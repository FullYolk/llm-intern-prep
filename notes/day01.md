npm:是 Node.js 默认的包管理器。
pnpm:npm 在每个项目中都会完整复制一份依赖，导致极其占用磁盘空间并且安装慢。pnpm 使用了“全局存储 + 硬链接/软链接”的技术，多个项目如果用了同一个包的同一个版本，在硬盘上只存一份。速度极快，且省空间。
uv:高速包管理器，解析依赖和安装包的速度是 pip 的几十倍甚至上百倍。
虚拟机与Docker：虚拟机（VM）是在硬件级别的虚拟化，每个虚拟机都有自己完整的独立操作系统内核，非常笨重，启动慢。Docker 是操作系统级别的虚拟化（容器化），所有的容器共享宿主机的同一个系统内核。容器只是一个被隔离的进程，所以 Docker 极其轻量、秒级启动，能在单台机器上跑成百上千个。（操作系统级/进程级）
使用subprocess.run：当你传给 Python 一个列表 ["git", "--version"] 时，Python 绕过了 Shell 的字符串解析过程。它直接调用底层的操作系统 API（在 Linux 下是 exec 系列函数），告诉操作系统：“去执行名叫 git 的程序，并把 --version 作为它的第一个独立参数传给它。”如果你在 subprocess 里非要传一个带空格的字符串，你必须加上 shell=True 这个参数，比如：subprocess.run("git --version", shell=True)。
但在企业级开发（尤其是 Agent 开发）中，极度不推荐使用 shell=True！
原因：这会引发命令注入漏洞（Command Injection）
