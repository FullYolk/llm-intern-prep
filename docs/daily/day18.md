基本符合预期
* 目前 每次用户请求时 都要重新初始化一次向量库 在高并发下会导致严重的IO与内存占用
* 后续可以使用单例模式或进行全局初始化 或使用Lifespan启动时间加载 在生产环境抽离成全局复用的单例
* 限制字符：防止日志污染 节约存储和保护隐私
* 使用**解包字典 Pydantic会自动进行数据校验和类型转换，它会遍历字典里的 sources 列表，把里面每一个普通的 dict，自动转换成 SourceItem 实例。最后，FastAPI 拦截到这个 AskResponse 对象，又会在底层调用 .model_dump_json()，把它序列化（Serialization）成标准的 JSON 字符串通过 HTTP 返回给前端。
* 绝对不会把真实的错误栈信息暴露给前端！
